# 🍔 Food Delivery Sales Dashboard — Power BI

An interactive Power BI dashboard analyzing **86,894 food delivery orders** 
across 4 major Indian cities from May–August 2015.

## 📊 Dashboard Preview
![Dashboard Preview](dashboard-preview.png)

## 📌 Key Metrics
- 💰 Total Revenue: ₹5,00,23,793
- 📦 Total Orders: 86,894
- ⭐ Average Rating: 3.50 / 5
- 🚚 Avg Delivery Time: 15 minutes
- 🍳 Avg Prep Time: 17.8 minutes

## 🏙️ Cities Covered
| City | Revenue |
|------|---------|
| Delhi | ₹1,34,37,998 |
| Bangalore | ₹1,27,34,277 |
| Chennai | ₹1,23,59,213 |
| Mumbai | ₹1,14,92,305 |

## 🍽️ Restaurants Analyzed
Haldiram, KFC, Annapoorna, McD, Barbeque Nation, 
Subway, Dominos, Starbucks, Pizza Hut, Bikanervala

## 🛠️ Tools Used
- **Power BI Desktop** — Dashboard & Visualizations
- **Microsoft Excel** — Raw Data (5 related tables)
- **Data Modelling** — Joined 5 tables on Order_ID

## 📁 Files
- `Sales_Dashboard111.pbix` — Power BI dashboard file
- `Sale_raw_data__7_.xlsx` — Raw dataset (86K rows, 5 sheets)
- `dashboard-preview.png` — Dashboard screenshot
